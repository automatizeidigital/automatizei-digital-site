# Automatizei Digital — versão em arquivo único

Esta versão foi preparada para publicação manual no GitHub e na Vercel.

O arquivo `index.html` já contém:

- todo o estilo do site;
- as funções de navegação;
- a logo;
- todas as imagens das propagandas.

## Como publicar

1. Envie o arquivo `index.html` para a raiz do repositório no GitHub.
2. A Vercel fará uma nova publicação automaticamente se o repositório já estiver conectado.
3. Não é necessário criar ou enviar uma pasta `assets`.

O `README.md` é apenas informativo e não interfere no site.
